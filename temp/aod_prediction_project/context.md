# Context for Copilot Agents

## Current Status

This folder contains a **minimal working subset** of the aod_prediction_project for Copilot Agents to understand and extend.

## Files Included

- **configs/**: YAML configs for SPADEJvM and CFM training
- **models/jvm/**: Partially implemented SPADEJvMLightningModule
- **models/stvmamba/**: STVMamba modules (need bottleneck integration)
- **models/simvp/**: Reference SimVP architecture for MetaFormer pattern
- **datasets/**: Data loading interface
